Življenje v antičnem Rimu

Vsakdanje življenje

Življenje Rimljanov se je razlikovalo glede na njihov družbeni položaj. Bogati so živeli v razkošnih vilah, medtem ko so revnejši prebivali v večstanovanjskih zgradbah, imenovanih insule. Dan se je pogosto začel zgodaj, z delom, šolo ali političnimi dejavnostmi.

Hrana in prehrana

Osnova rimske prehrane so bili kruh, oljčno olje in vino. Pogosto so jedli tudi zelenjavo, sadje in ribe. Bogatejši sloji so si lahko privoščili bolj raznolike in razkošne jedi, vključno z mesom in eksotičnimi specialitetami.

Zabava in prosti čas

Rimljani so imeli radi zabavo. Obiskovali so gledališča, kopališča in arene. Gladiatorske igre in dirke s kočijami so bile izjemno priljubljene in so privabljale množice gledalcev.

Izobraževanje in kultura

Izobraževanje je bilo pomembno predvsem za dečke iz bogatih družin. Učili so se branja, pisanja, retorike in filozofije. Rimljani so cenili umetnost, arhitekturo in literaturo, ki so jo pogosto prevzemali in razvijali iz grške kulture.
