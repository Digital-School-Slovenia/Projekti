2. SVETOVNA VOJNA

Začetek vojne

2. svetovna vojna se je začela leta 1939, ko je Nemčija napadla Poljsko. To je sprožilo globalni konflikt. Vojna se je hitro razširila po Evropi.

Zavezniki

Zavezniki so bile države, ki so se borile proti Nemčiji, Italiji in Japonski. Glavne so bile ZDA, Velika Britanija in Sovjetska zveza.

ZDA

ZDA so se pridružile vojni leta 1941 po napadu na Pearl Harbor. Imele so ogromno industrijsko moč in so izdelovale orožje v velikih količinah.

Velika Britanija

Velika Britanija se ni predala kljub močnemu bombardiranju Londona. Winston Churchill je bil simbol odpora.

Sovjetska zveza

Sovjetska zveza je imela eno največjih vojsk in je ustavila Nemce pri Stalingradu. Nato je začela potiskati Nemce nazaj proti Berlinu.

Orožje

V vojni so uporabljali tanke, letala, podmornice in topove. Tehnologija orožja se je zelo hitro razvijala.

Konec vojne

Vojna se je končala leta 1945 z porazom Nemčije in Japonske. Svet je bil po vojni močno spremenjen.
