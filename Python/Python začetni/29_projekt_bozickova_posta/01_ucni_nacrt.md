# 29 – Projekt – Božičkova pošta

## Kaj delamo

Učenci izdelajo igro, kjer Božiček lovi dobre emaile, se izogiba spamu in izgublja življenja.

## Cilji

- okno,
- Božiček se premika levo/desno,
- z vrha padajo predmeti,
- dober email doda točko,
- spam odvzame življenje,
- igra se konča, ko zmanjka življenj.
