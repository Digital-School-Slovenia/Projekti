# Domača naloga – 28 – Projekt – Mini Zelda

Naloge reši samostojno in po vsaki večji spremembi svoj odgovor ali program preveri. Če se zatakne, si najprej pomagaj z učnim listom tega sklopa, šele nato poglej rešitev ali vprašaj za pomoč.

### Naloga 1
Dodaj eno novo nadgradnjo, ki je danes nisi naredil.

### Naloga 2
V komentar zapiši, kateri del kode skrbi za:

- kamero,
- pobiranje kovancev,
- napad.

### Naloga 3
Pripravi 4-vrstični opis svoje igre:

- kaj je cilj,
- kdo je igralec,
- kdo je sovražnik,
- kdaj je zmaga ali poraz.
