# 28 – Projekt – Mini Zelda

## Kaj delamo

Učenci izdelajo preprosto top-down igro v slogu Zelda:

- igralec se premika po svetu,
- kamera mu sledi,
- pobira kovance,
- sovražniki ga lovijo,
- igralec lahko napade.

## Cilji

- gibanje igralca,
- kamera,
- vsaj nekaj kovancev,
- vsaj en sovražnik,
- score ali HP,
- osnovni napad ali trk s sovražnikom.
