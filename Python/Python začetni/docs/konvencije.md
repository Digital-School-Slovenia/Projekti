## Slog pisanja

- navodila naj bodo kratka in operativna,
- manj prazne razlage, več konkretnega dela,
- če dodaš razlago, naj služi nalogi,
- izogibaj se preveč akademskemu tonu,
- checkpointi in vmesni testi so dobrodošli.
