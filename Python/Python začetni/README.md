# Python začetni – 35 sklopov učnega programa

Ta mapa vsebuje celoten začetni program za učenje Pythona po načelu learning by doing. Gradivo je pripravljeno za delo v razredu: vsak sklop vključuje učni načrt, učni list, rešitve, dodatne naloge, domačo nalogo, referenčni Python primer in učiteljski scenarij ure.

## Kaj vsebuje posamezen sklop

- `01_ucni_nacrt.md`: pregled ciljev, poteka ure in minimalnih pričakovanih dosežkov.
- `02_ucni_list.md`: jedrni delovni list za učence.
- `03_resitev.md`: učiteljska orientacija z jedrom rešitve in tipičnimi napakami.
- `04_dodatne_naloge.md`: nadgradnje za hitrejše učence ali dodatno utrjevanje.
- `05_domaca_naloga.md`: krajši samostojni domači preizkus razumevanja.
- `06_*.py`: referenčna ali učiteljska Python datoteka za prikaz ključnih idej sklopa.
- `08_uciteljski_scenarij_ure.md`: izvedbeni scenarij z ritmom ure, vprašanji in opozorili.

## Pedagoška usmeritev

- Poudarek je na kratkih, konkretnih nalogah in pogostem preverjanju delovanja kode.
- Učitelj z rešitvijo usmerja, ne rešuje cele naloge namesto učenca.
- Učenec naj po vsaki večji spremembi kodo zažene, preveri izpis in odpravi napako.
- Projektni sklopi so zasnovani postopno: najprej delujoče jedro, nato nadgradnje.

## Opombe o datotekah Python

- V zgodnjih sklopih so Python datoteke kratki referenčni primeri.
- V projektnih sklopih so Python datoteke namenjene predvsem učiteljski demonstraciji in varni nadgradnji po korakih.
- Imena datotek se pri večjih projektih namenoma razlikujejo (`uciteljska_resitev`, `predloga`, `nadgradnja`), ker opisujejo različno vlogo datoteke v procesu pouka.

## Trenutno stanje paketa

- sklopi imajo usklajeno osnovno strukturo,
- domače naloge in projektni sklopi imajo dodatna navigacijska pojasnila,
- referenčni Python primeri so opremljeni z jasnejšimi komentarji o namenu in uporabi.
