# Python začetni – 35 sklopov učnega programa

Ta mapa vsebuje celoten začetni program za učenje Pythona po načelu learning by doing. Gradivo je pripravljeno za delo v razredu in za samostojno delo doma: vsak sklop ima kratek učni načrt, učni list, dodatne naloge, domačo nalogo in Python rešitve v podmapi `resitve`.

## Kaj vsebuje posamezen sklop

- `01_ucni_nacrt.md`: kratek pregled sklopa z razdelkoma `Kaj delamo` in `Cilji`.
- `02_ucni_list.md`: glavni delovni list za učence.
- `04_dodatne_naloge.md`: nadgradnje za hitrejše učence ali dodatno utrjevanje.
- `05_domaca_naloga.md`: krajši samostojni domači preizkus razumevanja.
- `resitve/01_ucni_list_resitve.py`: glavna rešitev učnega lista.
- `resitve/02_dodatne_naloge_resitve.py`: rešitve dodatnih nalog.
- `resitve/03_domaca_naloga_resitve.py`: rešitve domače naloge.
- `06_*.py`: dodatna referenčna ali demonstracijska Python datoteka tam, kjer je to pedagoško smiselno.
- `07_*.py`: pri nekaterih projektnih sklopih dodatna nadgradnja ali alternativna različica.

## Pedagoška usmeritev

- Poudarek je na kratkih, konkretnih nalogah in pogostem preverjanju delovanja kode.
- Rešitve so ločene od učnih listov, da učenec najprej poskusi sam, šele nato preveri pristop.
- Učenec naj po vsaki večji spremembi kodo zažene, preveri izpis in odpravi napako.
- Projektni sklopi so zasnovani postopno: najprej delujoče jedro, nato nadgradnje in izboljšave.

## Opombe o datotekah Python

- V zgodnjih sklopih so Python datoteke kratki referenčni primeri ali demonstracije ključne ideje ure.
- V projektnih sklopih Python datoteke pogosto prikazujejo eno glavno rešitev in eno ali več nadgradenj.
- Datoteki `06_predloga_igre.py` in `06_predloga_zakljucni_projekt.py` ostajata kot namenski začetni ogrodji za 34. in 35. sklop.

## Trenutno stanje paketa

- sklopi imajo enotno osnovno Markdown strukturo,
- vse rešitve so zbrane v podmapah `resitve`,
- projektni sklopi imajo dodatna pojasnila za postopno gradnjo iger ali zaključnega projekta,
- referenčni Python primeri in glavne rešitve so očiščeni najbolj očitnih zastarelih ostankov.
