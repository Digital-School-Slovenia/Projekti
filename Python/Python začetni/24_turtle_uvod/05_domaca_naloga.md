# Domača naloga – 24 – Turtle – uvod v risanje s funkcijami

## Obvezni minimum

- `t` je **želva**, ki riše
- vse ukaze pišemo kot `t.ukaz()`
- `"red"`, `"blue"`, `"green"`

## Bonus / za hitrejše

- `t.left()` / `t.right()`
- `t.color()`

## Kratka refleksija

Ob oddaji dopiši še:

- kaj ti je delovalo takoj,
- kje si se ustavil ali zmotil,
- kaj si popravil sam,
- katero nalogo bi še rad nadgradil.
