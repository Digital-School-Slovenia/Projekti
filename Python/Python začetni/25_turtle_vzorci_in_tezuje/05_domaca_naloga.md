# Domača naloga – 25 – Turtle – zahtevnejši vzorci in problemsko risanje

## Obvezni minimum

- Nariši hiško iz kvadrata in strehe.
- Nariši tri vedno večje kvadrate.
- Nariši barvni kvadrat.

## Bonus / za hitrejše

- Nariši spiralo.
- Nariši mandalo iz ponavljajočih oblik.

## Kratka refleksija

Ob oddaji dopiši še:

- kaj ti je delovalo takoj,
- kje si se ustavil ali zmotil,
- kaj si popravil sam,
- katero nalogo bi še rad nadgradil.
