# 33 – Projekt – Dodge the Meteors

## Trajanje

- 1 srečanje = 2 uri

## Kaj naredimo v tej uri

Učenci izdelajo igro, kjer ladja preživi čim dlje in se izogiba meteorjem.

## Do konca ure mora delovati

- ladja,
- premik levo/desno,
- spawn meteorjev,
- padanje meteorjev,
- trk,
- `game over`.

## Če ostane čas

- score,
- restart,
- ščit,
- power-up,
- naraščajoča težavnost.
