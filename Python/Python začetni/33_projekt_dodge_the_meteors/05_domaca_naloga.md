# Domača naloga – 33 – Projekt – Dodge the Meteors

## Obvezni minimum

- Ustvari ladjo kot `Rect`.
- Dodaj premikanje levo/desno.
- Nastavi timer za spawn meteorjev.

## Bonus / za hitrejše

- Dodaj točke preživetja.
- Dodaj različne velikosti ali hitrosti meteorjev.

## Kratka refleksija

Ob oddaji dopiši še:

- kaj ti je delovalo takoj,
- kje si se ustavil ali zmotil,
- kaj si popravil sam,
- katero nalogo bi še rad nadgradil.
