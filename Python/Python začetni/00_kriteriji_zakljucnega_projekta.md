# Kriteriji zaključnega projekta

## Obvezni minimum

Projekt:
- se zažene brez očitne katastrofe,
- ima jasno osnovno jedro,
- uporablja vsaj 3 večje sklope znanja iz tečaja,
- ga učenec zna demonstrirati od začetka do konca.

## Dober projekt

Poleg minimuma ima še:
- preglednejšo strukturo kode,
- manj očitnih napak,
- eno ali dve smiselnI nadgradnji,
- jasnejši uporabniški tok.

## Zelo dober projekt

Poleg vsega zgoraj še:
- dobro izpeljan zaključek / restart / meni / HUD ali primerljivo nadgradnjo,
- dve samostojni izboljšavi,
- vidno testiranje in sprotno popravljanje napak,
- dobro kratko predstavitev.

## Kaj učitelj ocenjuje najprej

1. Delovanje.
2. Razumevanje.
3. Smiselnost obsega.
4. Nadgradnje.
5. Lepota kode.

V tem vrstnem redu. Ne obratno.
