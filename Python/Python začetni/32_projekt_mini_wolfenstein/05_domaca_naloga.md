# Domača naloga – 32 – Projekt – Mini Wolfenstein

Naloge reši samostojno in po vsaki večji spremembi svoj odgovor ali program preveri. Če se zatakne, si najprej pomagaj z učnim listom tega sklopa, šele nato poglej rešitev ali vprašaj za pomoč.

### Naloga 1
Spremeni mapo in dodaj svojo postavitev labirinta.

### Naloga 2
Dodaj eno nadgradnjo: miška, cilj, vrata ali ključ.

### Naloga 3
V komentar zapiši, kateri del kode preverja, ali žarek zadene steno.
