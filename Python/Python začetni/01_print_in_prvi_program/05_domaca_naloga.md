# Domača naloga – 01 – Print, prvi program in delo v Thonnyju

Naloge reši samostojno in po vsaki večji spremembi svoj odgovor ali program preveri. Če se zatakne, si najprej pomagaj z učnim listom tega sklopa, šele nato poglej rešitev ali vprašaj za pomoč.

### Naloga 1
Napiši program, ki izpiše tvoje ime.

### Naloga 2
Napiši program, ki izpiše tvojo najljubšo hrano.

### Naloga 3
Napiši program, ki izpiše nekaj čisto trapastega, na primer `"Banana je predsednik sveta."`

### Naloga 4
Z enim ali dvema stavkoma zapiši, pri kateri nalogi si se ustavil in kako si težavo rešil ali bi jo še rešil.
