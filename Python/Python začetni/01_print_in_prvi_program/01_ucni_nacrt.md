# 01 – Print, prvi program in delo v Thonnyju

## Kaj delamo

Print, prvi program in delo v thonnyju – delo skozi naloge, sprotno testiranje in čim manj prazne razlage.

## Cilji

- Sestavi delujoče jedro za sklop »Print, prvi program in delo v Thonnyju«
- Med delom pogosto zažene program in preverja rezultat
- Reši več krajših nalog in ne obstane pri eni sami
- Zna pokazati osnovno rešitev in vsaj eno nadgradnjo
